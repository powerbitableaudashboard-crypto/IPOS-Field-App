Device Settings

Default device request amounts

💵 Default Amount — Cash

Auto-fills "Device amount" when a trainer selects Cash as the payment type on their Device Request form. Trainers can still edit it per request.

📇 Default Amount — Credit

Auto-fills "Device amount" when a trainer selects Credit as the payment type on their Device Request form.

📆 Credit Facility Terms

Shown to trainers as the repayment plan on Credit device requests (e.g. deposit now, then a fixed installment amount over N months).

📄 Contract Template

Upload the master contract (PDF, max 3MB) — every trainer can download it from the Contracts section.

📱 Device Types

Devices trainers can pick from on the Device Request form. Starts with H10 — add more as new devices become available.

📧 Device Request Recipients

The people trainers can pick as the main recipient or CC when requesting a device — trainers select from this list, they can't type their own emails.
